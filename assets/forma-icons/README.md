# Forma presentation icons

Three matching white outline icons with transparent backgrounds. Each PNG is 1024 × 1024 pixels; SVG versions can be resized without losing sharpness. Insert the PNG or SVG above the matching slide heading and use the same size for all three.

- `gpt-live-1`: speech bubble and waveform.
- `visual-understanding`: eye and 3D cube.
- `agents-api`: connected tool nodes.

Final icons were drawn as clean SVG geometry to match the outline style used by the presentation and frontend. PNGs are rendered from those SVGs. `preview.png` shows all three on black; use the individual files for your slide.
